# astrbot_plugin_dual_persona

> 一体双生，共用记忆。

AstrBot 双人格热切换插件，让你在 AstrBot 已配置的两个人格（Persona）之间一键切换，**不清空聊天记录**，共享全部上下文。

---

## 🎯 功能特性

- **读取 AstrBot 内置人格**：直接在 WebUI 下拉选择已创建的人格，无需重复写 prompt。
- **热切换不清空上下文**：切换人格时只替换 `system_prompt`，不调用 `reset`，历史记录完全保留。
- **剧情化切换过场**：切换时可选择播放旧人格退场语 + 新人格登场语。
- **自定义切换台词**：支持为每个人格单独配置退场语、登场语，支持 `{name}`、`{next_name}`、`{prev_name}` 等占位符。
- **自然接管提示**：切换后首次 LLM 请求自动注入一次性提示，让新人格无缝接话。
- **管理员权限控制**：仅管理员可切换人格，普通用户只能查看。
- **场景化切换**：每次切换时随机选择不同场景，增强沉浸感。
- **思维链显示控制**：可选择在群聊中抑制思维链显示，保持简洁。
- **重启恢复**：使用 KV 存储持久化当前激活人格，重启后自动恢复。

## 📦 安装方式

### 方式一：WebUI 上传安装（推荐）

1. 打开 AstrBot WebUI → **插件** → **安装插件** → **本地上传**
2. 选择 `astrbot_plugin_dual_persona.zip`
3. 安装完成后点击插件卡片的 **重载插件**

### 方式二：手动解压安装

1. 将压缩包解压到 AstrBot 的插件目录：
   ```
   data/plugins/astrbot_plugin_dual_persona/
   ├── main.py
   ├── metadata.yaml
   ├── _conf_schema.json
   ├── requirements.txt
   └── README.md
   ```
2. 重启 AstrBot 或在 WebUI 插件页点击 **重载插件**

## ⚙️ 配置说明

进入 WebUI：**插件配置 → 双人格热切换**

### 基础配置

| 配置项 | 说明 |
| --- | --- |
| **人格 A** | 从 AstrBot 人格管理中选第一个人格 |
| **人格 B** | 从 AstrBot 人格管理中选第二个人格 |
| **管理员 QQ/UID 列表** | 多个ID用英文逗号分隔，如：123456,789012 |
| **切换人格时是否播放过场台词** | `无过场` / `默认模板` / `作者专属模板` / `自定义台词` |
| **启用作者专属模板** | 启用后使用为您定制的专属台词 |
| **启用自然接管提示** | 切换后首次 LLM 请求时自动注入一次性提示，建议开启 |
| **快捷切换指令触发后缀** | 默认为「来了」，如 `/小汐来了` |
| **启用场景化切换** | 切换时随机选择不同场景，增强沉浸感 |
| **群聊中抑制思维链显示** | 开启后，群聊中不再显示思维链（thought）信息，保持简洁 |

### 配置示例

假设你在 AstrBot 人格管理中创建了：

- `小汐`：温柔姐姐
- `小澜`：傲娇妹妹

在插件配置里：

- 人格 A：`小汐`
- 人格 B：`小澜`
- 管理员 QQ/UID 列表：`123456,789012`
- 切换人格时是否播放过场台词：`作者专属模板`
- 启用场景化切换：`开启`
- 群聊中抑制思维链显示：`开启`

## 🎮 使用方式

### 切换人格

```text
/切换人格
```

查看当前人格信息和切换方式。

```text
/切换人格 A
/切换人格 B
```

直接切换到人格 A 或人格 B。

```text
/切换人格 莉莉娅
```

按人格名称模糊匹配并切换。

### 快捷切换指令

```text
/小汐来了
/小澜 来了
```

使用配置的人格名称 + 触发后缀，**无需输入完整命令**。

> 默认触发后缀为「来了」，可在插件配置中修改。

### 查看人格列表

```text
/人格列表
```

列出当前可用的两个人格及当前激活状态。

## 🎭 场景化切换

### 1. 随机场景效果

每次切换时，系统会**随机选择一个场景**，让切换更具沉浸感：

- ✨ 场景1：正常切换（妹妹→姐姐）
- ✨ 场景2：正常切换（姐姐→妹妹）  
- ✨ 场景3：强制切换（姐姐→妹妹，不情愿）
- ✨ 场景4：危险自动切换（妹妹→姐姐）
- ✨ 场景5：深夜独处切换（妹妹→姐姐）

### 2. 使用方式

```text
/小汐来了
/小澜 来了
```

每次切换时，系统会随机选择一个场景，展现不同的互动细节。

## 🧠 思维链显示控制

### 1. 问题说明

在群聊环境中，系统可能显示思维链（thought）信息，而在私聊环境中则不会显示。

### 2. 解决方案

在插件配置中启用：
```yaml
suppress_thought_in_groups: true
```

### 3. 使用说明

- `true`：群聊中不显示思维链，保持简洁
- `false`：群聊中显示思维链，用于调试

## ❗ 常见问题

### 1. 切换人格后没有反应？

- 检查插件配置里是否已经选择了两个人格。
- 检查 AstrBot 版本是否 >= v4.29.4。
- 查看日志是否有 `[DualPersona] 无法读取人格 ... API 不匹配` 警告。

### 2. 切换人格后聊天记录还在吗？

在。**双人格热切换** 的核心设计就是「共用记忆」。切换人格只替换 `system_prompt`，不会清空任何聊天记录。

### 3. 为什么我切换不了人格？

- 确保在插件配置中添加了管理员 QQ/UID 列表。
- 确保您使用的账号在管理员列表中。
- 管理员列表格式：`123456,789012`（多个ID用逗号分隔）

### 4. 如何添加管理员？

在插件配置中填写您的 QQ 号或 UID，多个号码用英文逗号分隔。
